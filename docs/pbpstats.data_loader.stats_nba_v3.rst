stats.nba.com Play-by-Play V3 Data Loaders
==========================================

stats.nba.com play-by-play V3 data loaders are used to load data for a specific resource either from file stored on disk or via an API request to `stats.nba.com <https://www.stats.nba.com/>`_. Events decide from V3's own labels with native event classes, and get the original's enhancement and possession decisions.
