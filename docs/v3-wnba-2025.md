# WNBA support: 2025 paired season — October 6, 2026

The adapter now accepts WNBA game IDs (`10…`). The fetch tool requests them from `stats.wnba.com`, the host the original uses for WNBA. G League IDs (`20…`) stay rejected: there is no G League evidence yet.

The evidence is the same kind as for the NBA. shufinskiy/nba_data has PlayByPlayV2 and PlayByPlayV3 exports of the WNBA 2025 regular season at the pinned revision `e829d467`. Both archives are vendored under `tests/parity/data/nba_data/`, with their hashes and upstream Git blob IDs in `tests/parity/paired-season-evidence-wnba-2025.json`. One game, `1022500001`, was also recorded live from `stats.wnba.com`, and its export rows equal that response exactly.

## Results

| Check | Result |
| --- | --- |
| Pairing | All 110,003 V2 events in 286 games pair one-to-one with V3; period, actor and actor team agree on every event |
| Clocks and order | V2's clock is the floor of V3's for every event; order differs only inside a clock instant, in 226 games |
| V3 labels | 154, each with exactly one V2 code |
| Decoder | Produces the recorded V2 code for 154 of 154 labels; before this change it matched 151 and rejected 3 |
| Full games, equivalent facts | **167 of 167 comparable games identical** |
| Live 2026 playoff games | 9 of 12 parse, one with a reviewed starter correction, all with final scores equal to the box score; 3 rejected for declared reasons |

The three new codes are recorded only in WNBA data, so they decode for WNBA games alone; NBA games still reject them:

| V3 label | V2 code | Events in 2025 |
| --- | --- | ---: |
| Timeout: Official | 9, 4 | 448 |
| Timeout: Reset | 9, 6 | 168 |
| Free Throw Clear Path 1 of 1 | 3, 40 | 1 |

The original's free-throw groups do not include code 40. The adapter reproduces what the original does with it on V2.

NBA results do not change. The NBA 2024-25 season differential is identical game by game in all three modes, and every 2025-26 corpus audit outcome is unchanged.

Three other rules are now league-specific:

- **Team heaves:** these stay NBA facts from 2025-26, since there is no WNBA evidence for them.
- **Starter overrides:** the original's `IntDecoder` keeps only leading-zero NBA game IDs as strings, so the original looks up other leagues' override games by integer ID. The adapter's starter recovery now does the same. Before this change it never found a WNBA starter override.
- **Fouled-player gap:** in WNBA data, V2 names a fouled player for the season's one blank-subtype foul. The adapter therefore records that foul's missing fouled player as an unknown attribution, as it does for every foul type V2 names one for.

## Season differential

`python -m tools.parity.season_differential --season wnba-2025` runs every game the way the NBA season was run: the original on V2, and the adapter on V3 in three modes. Report: `.parity/season-differential-wnba-2025.json`, SHA-256 `baf9237a5421e1d959786ff0aa2290a01524facc27733bbd45a6b8f7809a63f8`. Its implementation hashes match the current adapter and tooling. The original completes 214 of 286 games offline. Of the 72 it rejects, 54 fail its possession-alternation check, 11 need its data.wnba.com order fallback and 7 need its boxscore starter fallback.

The pattern matches the NBA's. With equivalent facts, the adapter reproduces the original exactly. The fouled-player gap is the only exclusion. V3's own order changes possession membership but never credited counts. Exact V3 clocks change decisions in most games and add credited possessions; the NBA figure was +414 (+0.22%). The clock and order policies decided for the NBA apply unchanged.

With equivalent facts, 47 games are rejected only on V3. In 36 of them a team won the jump ball, which V3 does not record (54 such events in 2025). The other 11 have description names that the V3 actors alone cannot resolve. A further 12 games are rejected on both sides for different reasons.

## Live 2026 playoff games

`scripts/save_v3_possessions.py` in Cheeseburger fetched the 12 WNBA 2026 playoff games played by October 4. Eight parsed without help, including one overtime game, and each final score equals the official box score. Four were rejected at first:

- **Team-won jump balls:** 2 games.
- **Alternation failure:** 1 game fails the original's possession-alternation check.
- **Contradictory starter evidence:** 1 game, `1042600201`, fails the adapter's lineup guard.
  - The original's starter inference finds four Atlanta starters for the 4th quarter. It therefore falls back to its period-start `boxscoretraditionalv2` request, which the tool fetched.
  - That response lists the Knicks' Ionescu on the floor, and not Jones or Astier. The play-by-play, however, has Jones blocking a shot at 9:40 and Astier on the floor until she is substituted out at 6:27.
  - The original would have used those lineups without noticing; the adapter rejects the game instead.

That game now has a reviewed correction, in the original's `missing_period_starters.json` schema. Atlanta's fifth 4th-quarter starter is Hillmon, who records no event in the quarter:

- **No substitutions:** Atlanta made no 4th-quarter substitution, so its five 4th-quarter players each played 10:00 then.
- **Official minutes:** official game minutes less Q1–Q3 floor time, from the original's own lineups, leave 10:00 (within 0.2 s) for Bonner, Reese, Howard, Canada and Hillmon, and none for anyone else.
- **Whole game:** with the correction, every player's floor time on both teams equals the official minutes within 0.2 s.
- **Fallback box score:** it lists the same five Atlanta players, but its New York list contradicts the play-by-play, so it is not evidence.

`web.REVIEWED_CORRECTIONS` holds the correction. The fetch tool and the Cheeseburger script supply it as `V3Overrides`, only for the exact play-by-play bytes reviewed, which are recorded in `tests/parity/data/wnba`; other bytes for the game are refused. With it, the game parses: 168 possessions, credited 82 and 82, final 92–82. That makes 9 of the 12 playoff games.

Supplying this correction exposed the starter-override key difference described above.

## Limits

- G League is not supported.
- Only the WNBA regular season is paired; the playoffs were checked live but not against V2.
- Team-won jump balls and the fouled player still need evidence beyond the V3 stats feed, as for the NBA.
